# AGENTS.md

SkyShift's rules for every coding agent (Codex, Cursor, Gemini, Copilot, Claude or any other) live in the
CLAUDE.md files. They are written for Claude but apply to you exactly as written.

Before you change anything:
1. Read CLAUDE.md at the repo root: areas and owners, rules (branch, tests, PR, merge, deploy), domain facts, cloud.
2. Read the CLAUDE.md in every folder you will touch: core/, pipeline/, server/, web/, mcp/, scripts/,
   contracts/, fixtures/, infra/. Folder rules add to the root rules.
3. Read contracts/ for any interface you touch. Names, types and units must match exactly.

Don't add rules here. Change CLAUDE.md, so every agent reads the same rules.
